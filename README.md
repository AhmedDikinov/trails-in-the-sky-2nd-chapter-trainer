## Install notes (Windows)

1. Close Trails in the Sky 2nd Chapter before the first run of a new trainer build.
2. Unpack or run only what MoggyDay gave you for `trails-in-the-sky-2nd-chapter-trainer`.
3. Start the trainer, then start Trails in the Sky 2nd Chapter (or the order printed on the live page if it differs).
4. Enable one or two toggles, not the whole +55 list at once.
5. Make a spare save. God mode and resource edits are hard to undo if you overwrite the only slot.

Antivirus sometimes flags trainers. That is normal for this file class. Download again from the same URL if the hash on the site changes.

## If something does not work

- The game patched and the v1.2.0 heading is older than the Trails in the Sky 2nd Chapter build you launched — wait for MoggyDay to bump the page.
- You used a bookmark that is not `/f/trails-in-the-sky-2nd-chapter-trainer` — switch to the URLs in the table above.
- Only the DLL or only the EXE was copied from a friend — get the pair from the site.
- Overlay or other injectors are running — turn them off and retry.
